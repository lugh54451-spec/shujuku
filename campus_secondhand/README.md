# 校园二手交易平台数据库系统

在线访问网址：部署完成后填写 Render 生成的网址，例如 `https://campus-secondhand.onrender.com`

## 项目简介

本项目是一个校园二手交易平台数据库系统，使用 Python 标准库 Web 服务和 SQLite 数据库实现。系统包含商品、用户、订单、查询、数据操作、购买、统计视图、安全与恢复等页面，可通过云端网址直接访问。

## 云端部署方式

推荐部署到 Render，部署完成后即可获得公网网址，不需要老师本地运行代码。

1. 将本项目上传到 GitHub 仓库。
2. 打开 [Render](https://render.com/)，创建 `Web Service`。
3. 连接 GitHub 仓库。
4. 使用以下配置：
   - Language: `Python 3`
   - Build Command: `python init_db.py`
   - Start Command: `HOST=0.0.0.0 python -B app.py`
   - Instance Type: `Free`
5. 部署完成后，将 Render 提供的 `https://...onrender.com` 地址填写到本文档开头。

也可以使用仓库中的 `render.yaml` 自动配置部署。

## 页面功能

- 首页：平台数据概览和最近订单。
- 商品列表：展示商品编号、商品名、类别、价格、状态、卖家编号。
- 用户列表：展示用户编号、用户名、手机号。
- 订单列表：展示订单、商品、买家和日期。
- 查询中心：支持作业要求查询和自定义条件查询。
- 数据操作：支持自定义新增商品、修改价格、删除未售商品。
- 购买：使用事务完成下单，并阻止重复购买已售商品。
- 统计与视图：展示商品总数、分类统计、平均价格、发布最多用户、已售/未售商品视图。
- 安全与恢复：说明权限控制、并发购买和崩溃恢复。

## 数据库说明

数据库文件：`campus_secondhand.db`

初始化脚本：`schema.sql`

三张表：

- `user(user_id, user_name, phone)`
- `item(item_id, item_name, category, price, status, seller_id)`
- `orders(order_id, item_id, buyer_id, order_date)`

关键约束：

- 三张表均设置主键。
- 必要字段设置 `NOT NULL`。
- `item.seller_id` 引用 `user.user_id`。
- `orders.buyer_id` 引用 `user.user_id`。
- `orders.item_id` 引用 `item.item_id`。
- `orders.item_id` 设置唯一约束，保证每个商品最多交易一次。
- `item.status` 只允许 `0` 或 `1`。
- 订单插入前检查商品是否未售出，订单插入后自动将商品状态改为已售出。

## 安全性说明

普通用户只开放浏览、查询、购买等必要功能，不提供删除接口；管理员账号才允许进行删除。数据库层面可为普通用户配置只读或有限写入权限，不授予 `DELETE` 权限。

若只允许用户查询数据，可使用只读数据库账号或只读连接，并在应用层只开放查询路由，不暴露新增、修改、删除接口。

## 并发与恢复说明

两个用户同时购买同一商品时，可能出现重复下单。本系统通过事务、商品状态检查和 `orders.item_id` 唯一约束防止重复交易。

订单插入和商品状态更新放在同一个事务中。事务未提交时系统崩溃会回滚；事务提交后数据会保存在数据库文件中。实际部署时还应定期备份数据库。
