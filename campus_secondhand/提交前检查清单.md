# 提交前检查清单

1. 将 `campus_secondhand` 上传到 GitHub。
2. 在 Render 创建 Web Service。
3. Build Command 填 `python init_db.py`。
4. Start Command 填 `HOST=0.0.0.0 python -B app.py`。
5. 部署完成后，打开 Render 生成的公网网址确认网站可访问。
6. 把公网网址写到 `README.md` 第一行。
7. 用公网网址录制操作视频。
8. 按 `README.md` 的截图清单补充截图。
9. 压缩 `campus_secondhand` 文件夹，命名为 `[姓名]+[学号]`。
10. 视频命名为 `[姓名]+[学号]视频`。
11. 邮件主题写 `26数据库大作业+[姓名]`，发送到 `liuyichen@dlut.edu.cn`。
